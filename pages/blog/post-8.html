使用Go快速搭建简易后端

MoHanFox-2026-09-29

Go/精选

使用的Go模块:

  • Gin: Gin 专为构建 REST API、Web 应用和微服务而设计，适用于对速度和开发效率有要求的场景。
  • Gorm: GORM 通过将 Go 结构体（Go structs） 映射到数据库表来简化数据库交互。

    本章节使用 MySQL 数据库作演示

  • Viper: Viper是一个流行的Go库，用于处理各种配置需求和格式。它支持从多种来源读取配置，包括JSON、TOML、YAML、HCL、envfile和Java属性文件。
  • Go: Go 1.25 或更高版本

项目准备

  1. 创造你的Go目录
  2. 为你的项目装载以上模块
  3. 本项目以自定义的Go控制台模拟前端 + Go后端为示例进行
require (
	github.com/gin-contrib/cors v1.7.9          //官方的Cors，本章节也会提供定制Cors
	github.com/gin-gonic/gin v1.12.0
	github.com/spf13/viper v1.21.0
	gorm.io/driver/mysql v1.6.0
	gorm.io/gorm v1.31.2
)
  1. 开始编写你的简易后端

代码准备

  1. 创建你的第一个 Gin 应用
package main

import "github.com/gin-gonic/gin"

func main() {
  router := gin.Default()
  router.GET("/ping", func(c *gin.Context) {
    c.JSON(200, gin.H{
      "message": "pong",
    })
  })
  router.Run() // listens on 0.0.0.0:8080 by default
}

使用以下命令启动服务器：

go run main.go

在浏览器中访问 http://localhost:8080/ping 你应该会看到：

{"message":"pong"}

恭喜你，你可以把你的gin应用做大做强了！
