项目说明

该博客旨在总结自己的Go学习，同时帮助您理解一些Go后端常用的模块组合 本项目使用REST风格 此博客以短链生成网站为模板为例子

使用的Go模块:

  • Gin: Gin 专为构建 REST API、Web 应用和微服务而设计，适用于对速度和开发效率有要求的场景。
  • Gorm: GORM 通过将 Go 结构体（Go structs） 映射到数据库表来简化数据库交互。
  • Viper: Viper是一个流行的Go库，用于处理各种配置需求和格式。它支持从多种来源读取配置，包括JSON、TOML、YAML、HCL、envfile和Java属性文件。
  • Go: Go 1.25 或更高版本

代码准备

  1. 开始创建你的 Gin 应用
package main

import "github.com/gin-gonic/gin"

func main() {
  router := gin.Default()        //创建一个 HTTP 引擎，router 负责登记所有路由，建议进入Default方法挖掘其用了什么中间件（重点）
  router.GET("/ping", func(c *gin.Context) {        //为路由添加API, 处理函数签名。c 里装着请求和响应，c 一旦返回，这次请求就结束了
    c.JSON(200, gin.H{
      "message": "pong",
    })
  })
  router.Run()  // 不传参数时默认监听 0.0.0.0:8080
}

使用以下命令启动服务器：

go run main.go

cmd运行curl.exe -s http://localhost:8080/ping，你大概率会看到{"message":"pong"} 恭喜你，你可以把你的gin应用做大做强了！

拓展你的接口与Rest规则

Rest规则

RESTful（Representational State Transfer）是一套 面向资源的 API 设计方法论，而非强制标准，核心目标是让接口具备「可读性强、可扩展、无状态、跨平台」的特性，是目前前后端 / 移动端接口设计的主流规范。详细可见：

Gin 不是按 REST 规则设计的框架，它是一个通用的 Go HTTP Web 框架/路由框架。它“可以”用来写 RESTful API，而且很适合，但是否 RESTful 取决于你怎么设计接口，而不是 Gin 本身。

Gin 并不强制 REST：你可以用 Gin 写：https://blog.csdn.net/qq_37257657/article/details/81206520#

r.POST("/getUser", getUser)
r.GET("/deleteUser", deleteUser)

Gin 也可以很容易写 RESTful 风格：

r.GET("/users/:id", getUser)
r.POST("/users", createUser)
r.PUT("/users/:id", updateUser)
r.DELETE("/users/:id", deleteUser)

为了让你的项目可读，可积极使用RESTful风格，本项目使用REST风格为例

设计API

为了更好地管理您的路由，你可以在跟目录创建一个 Handler 文件夹，并创建router.go

func RegisterRoutes(r *gin.Engine) {
	r.GET("/health", func(c *gin.Context) {
		c.JSON(http.StatusOK, gin.H{"status": "ok"})
	})

	api := r.Group("/api/v1")
	{
		// 我们先从登录做起
		api.POST("/auth/register", Register)
		api.POST("/auth/login", Login)
	}
}

在 Handler 文件夹下创建 auth.go 表示这是专门管 账号 的go代码，在 auth.go 中创建一下代码：

func Register(c *gin.Context) {}
func Login(c *gin.Context) {}

接着，在main.go中路由

func main() {
	r := gin.Default()
	r.Use(GinCORSMiddleware())
	handler.RegisterRoutes(r)

	r.Run(":8080")    //在8080端口运行服务器
}

func GinCORSMiddleware() gin.HandlerFunc {
	c := cors.Config{
		AllowOrigins:     "",
		AllowMethods:     []string{"GET", "POST", "PUT", "DELETE", "OPTIONS"},
		AllowHeaders:     []string{"Origin", "Content-Type", "Authorization", "X-Requested-With"},
		ExposeHeaders:    []string{"Content-Length", "X-Total-Count"},
		AllowCredentials: true,
		MaxAge:           12 * time.Hour,
	}
	return cors.New(c)
}
